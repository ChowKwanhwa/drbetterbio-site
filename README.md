# drbetterbio — Skin Collection

Static product collection page for the drbetterbio skincare line.

- `index.html` — page markup
- `assets/css/style.css` — styles (mobile-first, 2 / 3 / 4-column grid)
- `assets/js/main.js` — sorting, category filter, grid density, add-to-bag feedback, newsletter validation
- `assets/data/products.json` — product catalogue (sample names and prices)
- `assets/img/` — product photography

Run locally:

```bash
python3 -m http.server 8080
# open http://localhost:8080
```
